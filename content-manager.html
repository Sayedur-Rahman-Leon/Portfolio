How it works

Edit without touching HTML

  1. Run the project with VS Code Live Server.
  2. Open content-manager.html.
  3. Select the JSON file you want to change.
  4. Edit and press Validate.
  5. Press Download JSON.
  6. Replace the old file in data/ with the downloaded file.

Google Drive media

Use a normal public Drive sharing link:

{"type":"video","title":"Demo","url":"https://drive.google.com/file/d/FILE_ID/view"}

Supported types: image, audio, video, and normal links.
